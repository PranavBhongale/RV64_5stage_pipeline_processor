## Project Documentation

All project information is clearly documented in the **Synopsis Report**. The report provides detailed information about the processor architecture, microarchitecture, design decisions, implementation, verification, limitations, and other aspects of the project.

The repository also contains dedicated folders for specific parts of the project, such as:

* **Instruction Support** — Supported instructions and their implementation details.
* **Architecture** — Processor architecture and microarchitectural details.
* **RTL** — Hardware implementation and pipeline modules.
* **Verification** — Testbenches, test programs, and verification-related files.

If you want to understand exactly what this project is and how the processor works, please go through the **Synopsis Report (PDF)** first. It provides a complete overview of the design and explains the major architectural and implementation decisions in detail.
